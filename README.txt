カードコレクター：プロファイル方式

■ 使い方
1. Web公開してSafariで開く
2. 「＋ インポート」からJSONプロファイルを選択
3. 弾ごとのプロファイルが追加される
4. プロファイルを切り替えてカードを管理
5. 所持・欲しい情報は端末内に保存

■ プロファイル形式
{
  "profileVersion": 1,
  "id": "unique-id",
  "name": "第2弾",
  "cards": [
    {
      "id": "E2-01_PR",
      "number": "E2-01",
      "rarity": "PR",
      "name": "カード名",
      "image": "https://..."
    }
  ]
}

■ 注意
プロファイル削除時、そのプロファイルの所持・欲しい情報も端末から削除されます。
